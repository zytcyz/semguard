Fine-Grained Ship Detection in Remote Sensing Images

SemGuard combines target–background separation, context regulation and structural feature modeling for fine-grained ship detection.

CW-VIB Module

The Causally Weighted Variational Information Bottleneck estimates background-prototype risk from prediction changes and standalone class responses. Risk-weighted compression and gated fusion regulate the contribution of context to target features.

Available Code

cwvib.py provides the PyTorch implementation of prototype intervention, variational encoding, weighted KL loss and context fusion. Input formats and a usage example are included in the source file.
